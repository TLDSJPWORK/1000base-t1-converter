# MATEnetアダプタ ケース

ツイストペア線接続型アダプタ基板用の上下分割ケースです。4か所のスナップ爪で固定し、ねじは使用しません。

## 造形・組立

PLA、0.2 mm積層、サポートなしの造形用データです。下ケースはそのまま、上ケースは`case-top-print-oriented.stl`の向きで造形します。
基板と電線を下ケースに収め、電線を挟まないよう確認して上ケースを取り付けてください。

| ファイル | 用途 |
| --- | --- |
| [case-bottom.stl](case-bottom.stl) | 下ケースの造形 |
| [case-top-print-oriented.stl](case-top-print-oriented.stl) | 上ケースの造形。ふたの外面を下に配置済み |
| [case-top.stl](case-top.stl) | 組立時の位置・向きに配置した上ケース形状 |
| [case-bottom.step](case-bottom.step) / [case-top.step](case-top.step) | 他CADでの編集・参照 |
