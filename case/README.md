# 1000BASE-T1コンバーター ケース

125 × 70 mm基板用の上下分割ケースです。
設計外形は132.8 × 77.8 × 28.0 mmです。

## 造形・組立

PLA、0.4 mmノズル、0.2 mm積層で造形しました。
上下ケースはM3×25 mmねじ4本とM3ナット4個で固定します。

上ケースの造形には、ふたの外面を下に配置した
`case-top-print-oriented.stl`を使用してください。
実際に使うねじ・ナットと造形条件で寸法を確認してください。
