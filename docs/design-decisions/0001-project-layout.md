# 0001: 開発フォルダと意思決定記録の配置

- 日付: 2026-09-11
- 状態: 開発フォルダ名のみ[0002](0002-software-name.md)で置換済み。記録配置は継続。

## 背景

1000BASE-T1コンバーターのファームウェア開発を開始するため、リポジトリ内に新しい作業フォルダを作成した。
あわせて、意思決定の記録を一旦ルート直下のまとまった場所に置くことになった。

## 決定

- ファームウェアの開発は `firmware/` で行う。
- 意思決定の記録はルート直下の `decisions/` にまとめる。

## 理由

ファームウェアの実装場所を明確にし、プロジェクト全体の判断の経緯を一か所から参照できるようにする。

## 影響

今後の意思決定は対象分野にかかわらず `decisions/` に記録する。
PHY設定や実機の測定結果など、意思決定そのものではない技術資料は各開発フォルダのドキュメントとして管理できる。
