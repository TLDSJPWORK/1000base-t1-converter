# 0003: KiCad 9.0側の回路図を根拠にする

- 日付: 2026-09-11
- 状態: 採用（参照先はユーザー指定、抽出方法は実装判断）

## 背景・決定

ユーザーが `KiCad/9.0/1000base-t1-converter` を指定した。
KiCad CLIのXMLネットリストを抽出し、部品・ネット・回路図SHA-256をソフトウェアのdocsへ保存する。
現時点ではメインにサブモジュール登録がなく、指定ディレクトリもGit管理されていなかったため、Git構造は変更しない。

## 理由

8.0側や既存スキャナーの仮定を混ぜず、どの回路図から判断したか再現できるようにする。
既存READMEのGPIO20リセットという記載は、回路図のRUN共通リセット配線と一致しないため採用しない。

## 影響

専用ボード定義を使用する。MDIO=GPIO4/MDC=GPIO5、リセットGPIOなし。
U206はDP83TG720R、U301はDP83867Eとして資料を選択する。
抽出JSONは根拠資料であり、実機実装状態の保証ではない。
