# 0004: PIOによるMDIOとUSB CDC操作

- 日付: 2026-09-11
- 状態: 採用（実装判断、実機検証待ち）

## 背景・決定

MDIOはPIO0の1ステートマシンを使い、公称2.5MHzで生成する。
全64ビットの送信情報を事前にFIFOへ入れ、CPU割り込みの影響を抑える。
読み取りはTAを2クロック確保して2ビット目のLOWを確認する。
待機・受信中はMDIO入力、MDCはフレーム間LOW。内部プルアップは無効とする。
USB CDCからscan/read/write/MMD操作とリンク監視を行う。単一コアから直列にアクセスする。

## 理由

既存ビットバンギングのMDCは推定値で、TAにも独自の省略処理がある。
該当PHYデータシートの仕様に沿うタイミングを再現可能にし、波形検証しやすくする。
MDIO外付けプルアップが回路図にないため、弱い内部プルアップで実装不備を隠さない。
USBは基板に存在し、未使用GPIOへUARTを割り当てる必要がない。

## 影響

タイムアウトとTA不成立をエラーにする。書き込みフレームにACKはないため成功を断定しない。
MMD読出しに伴うアドレス選択書き込みは文書化する。
PIO周期・電圧・TAは実測が必要。テストではフレーム構成とエラー伝播を確認する。
