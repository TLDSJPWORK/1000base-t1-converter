# 0005: 初回は診断起動と明示的レジスタ操作

- 日付: 2026-09-11
- 状態: [0011](0011-media-converter-profile.md)で置換済み

## 背景・決定

USBコマンド、PHYスキャン、レジスタ読み書き、リンク監視を初期実装とする。
起動時のPHY設定変更、GPIOリセット、フラッシュへの設定保存は行わない。
データ転送は基板のRGMII経路を利用する設計で、RP2040にはEthernetスタックを搭載しない。

## 理由

MDIOプルアップ、PHY実機ID、ストラップ値、相手のmaster/slaveとRGMII遅延が未確認。
根拠のない設定列を自動実行すると、誤ったPHY状態を作り原因の切り分けを難しくする。
診断機能で必要な実測値を取得してから、型番・リビジョンに適合する初期化を確定する。

## 影響

今回はコンバーターとしての自動起動完成版ではない。
自動初期化とEthernet双方向転送確認はdocs/validation.mdの未完了事項に残す。
write/mwriteは実機作業者が明示した操作だけを実行し、値の恒久保存はしない。

2026-09-14の実機疎通によりMirror解除とRGMII遅延値が確定したため、
自動初期化を保留する方針は0011で置き換えた。診断コマンドは継続する。
