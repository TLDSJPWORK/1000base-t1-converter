# 0006: ビルドと検証の扱い

- 日付: 2026-09-11
- 状態: 採用（実装判断）

## 背景・決定

既存Pico SDK 2.2.0とArm GNUツールチェーンを使い、専用RP2040ボード定義でビルドする。
ソフトウェアは親フォルダへのビルド依存を持たせない。
ホストテストとRP2040のクロスビルドを分離し、どちらも実行する。
本体が書き込み許可範囲外のため、一時ディレクトリで検証後、権限確認を経て対象へ反映する。

## 理由

将来の独立リポジトリ化を容易にする。
U602の2MiB Flashに合わせ、SDK標準のWinbond向けboot2を使う。
プロトコルの失敗系をハードウェアなしで検証しつつ、実機実行可能なUF2まで生成する。
必要な書き込みだけに権限を限定する。

## 影響

ビルド成果物はGit管理しない。実機書き込み・公開・コミットは今回の操作には含めない。
検証結果をソフトウェアdocs/validation.mdに残す。
自動承認機構によるファイル書き込み許可は、電気設計やPHY設定のユーザー承認とは区別する。
