# 0008: 同一ボード2台での試験準備

- 日付: 2026-09-13
- 状態: 採用（ユーザー指定のPC–converter–converter–Raspberry Pi構成）

## 決定と理由

両ボードを同時USB接続し、固有シリアル番号で区別する。
2台目にも同一の低速版0.1.1を書き込み、ハードウェア確認条件を揃える。
ユーザーの接続報告を受け、前の書き込み依頼の範囲で実行した。
唯一のBOOTSELデバイスへ-fなしで書き込み、通常動作中の1台目を対象にしない。
書き込み照合と2台目のPHY ID読み取りが成功した。

## 影響

両ボードとも管理・診断の準備ができた。master/slave・RGMII初期化と
PC/Pi間のデータ疎通は次の段階で設定・検証する。結果はdocs/validation.mdに保存した。
