# 0010: U203ジャンパをmaster/slave初期値の正とする

- 日付: 2026-09-13
- 状態: 採用（ユーザーが基板設計意図を明示し、実機確認を依頼）
- 置換対象: [0009](0009-t1-master-slave.md)の役割別UF2を通常運用する方針

## 決定

通常運用ではソフトウェアによるmaster/slave上書きを行わず、U203ジャンパの
電源投入時ストラップを使用する。1–4をmaster、2–3をslaveとする。
現在の2台には役割を上書きしないdiagnostic版0.2.0を使用する。

## 理由

master/slave初期値をスイッチで選択できることが基板の設計意図であり、
ソフト固定より先に回路の動作を確認する必要がある。電源再投入後の実測で、
ストラップ状態、PMA制御値、T1リンクのすべてが回路図の指定と一致した。

## 実機結果

- 1台目 U203=1–4: SOR_VECTOR_1=0x1128、PMA=0xC001、master
- 2台目 U203=2–3: SOR_VECTOR_1=0x1108、PMA=0x8001、slave
- 両台のT1リンク: up

## 影響

役割変更後はストラップを再ラッチさせるため、両ボードを完全に電源再投入する。
picotoolによるRP2040再起動だけではPHYがリセットされない場合がある。
master/slave役割別UF2はレジスタ上書き試験用として残すが、通常運用には使用しない。
