# 0011: メディアコンバーター用PHY設定を起動時に適用する

- 日付: 2026-09-14
- 状態: 採用（ユーザーが実機疎通後の設定ソフトのファイナライズを依頼）
- 置換対象: [0005](0005-initial-bringup-scope.md)の自動初期化保留

## 決定

通常のdiagnosticビルドを含む全ビルドで、起動時にDP83867のMirror modeを解除し、
RGMII TX/RX内部遅延を各2.0nsへ設定する。Mirror設定が変わる場合だけDP83867を
ソフト再起動し、その後に遅延を設定する。各レジスタは読み戻して結果をUSBへ表示する。
DP83867では遅延機能自体も明示的に有効化し、DP83TG720側の内部遅延は無効化する。
T1 master/slaveはU203のストラップを通常運用の正とし、diagnosticビルドでは変更しない。

## 理由

両基板で意図しないMirror modeがラッチされ、通常の1000BASE-T相手とリンクしなかった。
解除後はリンクしたが、RGMII遅延がTX=0.5ns、RX=2.0nsで、ARPフレームが通過しなかった。
TX/RXを2.0nsへ揃えるとARP、ping、SSHがすべて成功した。DP83TG720側の遅延は無効であり、
DP83867側だけに遅延を持たせれば重複を避けられる。

## 影響

RP2040起動後は追加操作なしでメディアコンバーターとして使用できる。
手動MDIOコマンドは診断用として維持する。PHY設定が読み戻しと一致しない場合は
`Media config result`にエラーを表示し、原因を隠して成功扱いしない。
