# 意思決定の記録

プロジェクト全体の意思決定を、このフォルダにまとめます。
回路・ファームウェア・開発環境など、対象にかかわらず同じ場所に記録します。

## 記録方法

- ファイル名は `0001-短い名前.md` のように連番を付けます。
- 日付、状態（提案・採用・撤回・置換済み）、背景、決定、理由、影響を記載します。
- 未確定の案は「提案」として、採用済みの決定と区別します。
- 決定を変更する場合は新しい記録を追加し、元の記録に置換先へのリンクを残します。
