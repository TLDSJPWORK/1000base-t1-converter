# Rev1.0の既知事項

Rev1.0の回路と製造出力を参照するときの注意点です。本文の「収録BOM」は[製造時のbom.csv](../production/bom.csv)、「実装位置データ（CPL）」は[positions.csv](../production/positions.csv)を指します。

## 部品と実装

- U206は、収録BOMの型番欄が`DP83TG720RWRHATQ1`、部品番号欄が`C2921292`となっています。C2921292に対応する型番は`DP83TG720SWRHARQ1`です。型番欄と部品番号欄に不整合があるため、再製造時は採用する部品に合わせて修正してください。
- R611はフラッシュのチップセレクト信号用の予備プルアップ抵抗で、`DNF`（未実装）です。本基板では未実装での実動作を確認しています。収録BOMでは値が`DNF`、部品番号は空欄です。部品変更時に備えてパッドを残しています。
- U602は`W25Q16JVUXIQ`です。今後の部品調達の選択肢を増やすため、`GD25Q16CEIGR`などの代替フラッシュを検討しています。代替品は実機での起動・読み書き確認が必要であり、Rev1.0の採用部品は変更していません。
- R219は`10.0kΩ`です。PHYの起動時ストラップ設定について、抵抗値のばらつきを含めた設定電圧の余裕を確保するため、Rev1.1では`13kΩ`への変更を検討しています。Rev1.0の設計・製造原本には反映していません。

## 接続と通信確認

RJ45のCペアは、回路図の正負ネット名とコネクター側の正負が反転しています。Ethernet PHYの自動極性判定・補正により、この反転がある状態でも実機で1000BASE-Tリンクと通信を確認しています。確認した構成・試験内容は[検証記録](https://github.com/TLDSJPWORK/1000base-t1-converter-soft/blob/main/docs/validation.md)を参照してください。Rev1.0の設計・製造原本には、この配線をそのまま収録しています。
