# 1000BASE-T / 1000BASE-T1 メディアコンバーター 取扱説明書

> Rev1.0用です。付属MATEnetアダプタは、ケース付きのツイストペア線接続型です。

## 1. 使用上の注意

- USB Type-Cから5 Vを供給してください。
- 配線やスイッチ設定を変更するときは、電源を外してください。
- T1配線の極性とmaster／slave設定を確認してから接続してください。
- PLAケースを高温や直射日光にさらさないでください。

## 2. 接続部と設定

| 表示・端子 | 用途 |
| --- | --- |
| RJ45 | 1000BASE-T |
| T1 | 1000BASE-T1。内部CN201はpin 1=T1_P、pin 2=T1_N |
| Master/Slave | master：1–4=ON・2–3=OFF。slave：1–4=OFF・2–3=ON |
| Sleep / WAKE | 通常動作（WAKE=High）：1–4=ON・2–3=OFF。Sleep要求（WAKE=Low）：1–4=OFF・2–3=ON |
| USB Type-C | 5 V給電、管理コンソール、ファームウェア更新 |
| Reset | RP2040と両PHY（DP83TG720・DP83867）の共通リセット |
| Boot | UF2ファームウェア書き込み時に使用 |

スイッチはそれぞれ一方の回路をON、もう一方をOFFに設定し、両回路を同時にONにしないでください。Sleepへの移行はPHYの設定やリンク状態にも依存します。
端子・スイッチ・LEDの位置と表示の意味は[基板の設定と説明](../README.md#基板の設定と説明)を参照してください。Reset LEDは共通リセット信号がLowの間に点灯し、Resetボタン操作時にも点灯します。

## 3. 接続手順

1. 全ての電源を外します。
2. T1リンクの一方をmaster、もう一方をslaveに設定します。
3. Sleepスイッチを通常動作側へ設定します。
4. T1側へ、極性を確認した1000BASE-T1配線を接続します。
5. RJ45へ1000BASE-T対応機器を接続します。
6. データ通信対応USB Type-Cケーブルで5 Vを供給します。
7. リンク状態を確認します。USB診断を使う場合は、`scan`でPHYを検出してから`status`を実行します。

役割設定はPHYの電源投入時に読み取られます。設定変更後はUSBだけでなく、基板の全電源を切って再投入してください。

給電にはUSB Type-Cの5 Vを使用してください。

### MATEnetアダプタの結線

アダプタの設計・製造・造形データは[adapter/](../adapter/)に収録しています。

付属アダプタは、本体のT1端子（CN201）とMATEnet A-codeを接続します。本体側の2極プラグ（C71370）とアダプタ基板をツイストペア線でつなぎ、基板を上下ケースに収めた構成です。信号の変換や増幅は行いません。

| 信号 | 本体CN201・本体側プラグ | アダプタ基板J2（電線接続側） | アダプタ基板J1（MATEnet側） |
| --- | --- | --- | --- |
| T1_P | pin 1 | pin 1 | pin 1 |
| T1_N | pin 2 | pin 2 | pin 2 |

```text
本体CN201 ── 2極プラグ ── ツイストペア線 ── J2 ── 基板配線 ── J1（MATEnet）
T1_P：pin 1 ─────────────────────────── pin 1 ─────────── pin 1
T1_N：pin 2 ─────────────────────────── pin 2 ─────────── pin 2
```

番号はコネクターの端子番号であり、見たときの左右ではありません。嵌合面と基板側では見え方が反転するため、左右や線色だけで判断せず、端子番号を確認してください。CN201にGND端子はありません。

1. 本体と対向機器の電源を外します。
2. アダプタの本体側プラグを、向きとキーを確認して本体CN201へ差し込みます。無理に押し込まないでください。
3. アダプタのMATEnet端子に対応するA-codeケーブルを接続し、対向機器までT1_P／T1_Nが対応する結線になっていることを確認します。
4. 上記の接続手順に従って、master／slaveとWAKEを設定してから給電します。

アダプタを外すときは、ケーブルを引っ張らずプラグ本体を持ってください。アダプタケースは4か所のスナップ爪で固定する構造です。

### ファームウェアの書込み（Boot）

本基板用の[専用ファームウェア](https://github.com/TLDSJPWORK/1000base-t1-converter-soft)を用意します。ソースからビルドする場合の出力は`build/converter_soft.uf2`です。ビルド方法はリンク先のREADMEを参照してください。

1. USBを含む全ての電源を外します。ケースを開ける必要がある場合も、この状態で行います。
2. 基板の**Boot（SW601）**を押し続けながら、データ通信対応USB Type-CケーブルでPCに接続します。
3. PCに**RPI-RP2**ドライブが表示されたら、Bootボタンを離します。
4. 本基板用の`converter_soft.uf2`をRPI-RP2ドライブへコピーします。書込みが完了するとドライブが消え、ファームウェアが起動します。
5. USB CDCシリアルを開き、起動ログの`Media config result: OK`を確認します。`scan`でPHYを検出してから、`status`でリンク状態を確認します。

Bootボタンだけを押しても、既に動作中のファームウェアはBOOTSELモードへ移行しません。上記の電源を外した状態から操作してください。書込み中は電源を外さないでください。

RPI-RP2が表示されない場合は、全電源を外してからBootを押したまま接続し直し、USBケーブルがデータ通信に対応していることを確認します。BOOTSELはRP2040内蔵ROMの機能で、通常のUSB診断とは別の動作です。[Raspberry Pi公式のUF2書込み説明](https://www.raspberrypi.com/documentation/microcontrollers/c_sdk.html)も参照できます。本基板には本基板用UF2を使用してください。

## 4. USB診断

USB CDCシリアルを開き、改行付きでコマンドを送ります。CDCのボーレート設定は任意です。

最初に`scan`でPHYを検出し、その後`status`で状態を確認します。`watch on`も、`scan`で検出したPHYを対象にリンク変化を監視します。

```text
scan
status
watch on
```

監視を停止する場合は`watch off`を実行します。

| コマンド | 機能 |
| --- | --- |
| `help` | コマンド一覧 |
| `scan` | PHYアドレス0～31を検出 |
| `status` | `scan`で検出したPHYとリンク状態を表示 |
| `watch on` / `watch off` | 1秒周期でリンク変化の監視を開始／停止 |
| `read PHY REG` | Clause 22レジスタ読出し |
| `write PHY REG VALUE` | Clause 22レジスタ書込み |
| `mread PHY DEV REG` | MMDレジスタ読出し |
| `mwrite PHY DEV REG VALUE` | MMDレジスタ書込み |

`write` と `mwrite` はPHYの状態を変更する診断機能です。内容を理解せずに使用しないでください。手動設定はRP2040のフラッシュには保存されません。

## 5. 正常動作の確認

- 起動ログに `Media config result: OK` と表示される
- 1000BASE-T PHYと1000BASE-T1 PHYがともに `link up` になる
- 1000BASE-T1の対向がmaster／slaveの一組になっている
- 実トラフィックが双方向に通る

## 6. トラブルシューティング

- T1リンクが上がらない: 対向のmaster／slave、全電源再投入、T1配線と極性を確認します。
- RJ45リンクが上がらない: `Media config result`、ケーブル、対向機器の1000BASE-T対応を確認します。
- USBに表示されない: データ通信対応USBケーブル、OSのシリアルデバイス、再接続を確認します。
- 通信が不安定: 電源品質、ケーブル、コネクタ、異常発熱を確認します。改善しない場合は使用を中止してください。

## 7. ケースと取扱い

- 材料: PLA（FDM造形）
- 外形設計値: 約132.8 × 77.8 × 28.0 mm
- 固定: M3×25ねじ4本、M3ナット4個
- 積層痕や軽微な表面差はFDM造形の特性です。
- ねじを過度に締めるとケースが割れるため、購入者による分解・再組立は推奨しません。
- ケースを開ける前に全てのケーブルと電源を外してください。
